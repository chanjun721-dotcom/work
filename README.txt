GitHub Pagesへの反映
1. ZIPを解凍します。
2. GitHubの chanjun721-dotcom/work リポジトリを開きます。
3. mainブランチの「Add file」→「Upload files」を選びます。
4. index.html、style.css、script.js、README.txt、assetsフォルダーをまとめてドラッグします。
   ZIPや親フォルダーそのものではなく、解凍後の中身をアップロードしてください。
5. 「Commit changes」で保存します。既存の3ファイルは更新され、assetsが追加されます。
6. GitHub Pagesの処理完了後、https://chanjun721-dotcom.github.io/work/ を再読み込みします。
